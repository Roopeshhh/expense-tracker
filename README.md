# 💰 Expense Tracker

A clean and responsive expense tracker built with HTML, CSS and JavaScript.

## Features

- Add income
- Add expenses
- Automatic balance calculation
- Total income calculation
- Total expense calculation
- Delete transactions
- Filter transactions
- Responsive design
- Clean and modern interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
